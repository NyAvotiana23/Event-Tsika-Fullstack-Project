# event-tsika (front Angular)

Application Angular 21 de E-Ventsika. Voir le [README racine](../README.md) pour le lancement complet et [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

```bash
npm ci
npm start              # http://localhost:4200, /api proxifié vers http://localhost:5104 (proxy.conf.json)
npm test               # vitest
npm run lint           # ESLint
npm run format:check   # Prettier
npm run build          # dist/event-tsika/browser
```
